# Project 2 — SQL E-Commerce Analysis (practice questions)

Database: `ecommerce.db` (SQLite) — tables: customers (30), products (10), orders (150).
CSV copies of all three tables are in this folder if you want to reload them yourself.
Type every query yourself; check against `ANSWERS.md` only after trying. `solutions.sql` holds the reference queries.

1. What is the total sales revenue?
2. How many orders came from each city? (orders → customers)
3. Which 5 products earned the most revenue?
4. What is the month-wise sales trend?
5. What is the average order value?
6. How many orders came from Hyderabad customers?
7. How much revenue did each product category earn?
8. Which customer spent the most overall?
9. Which products have never been ordered? (LEFT JOIN)
10. List all orders above Rs 20,000, labelled "High" or "Very High" (CASE WHEN).

Skills used: SELECT, WHERE, JOIN (INNER + LEFT), GROUP BY, ORDER BY, LIMIT, SUM/COUNT/AVG, CASE WHEN, date text handling.
